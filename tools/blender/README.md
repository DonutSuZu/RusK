# Blender で Custom Motion の動きを作る

Blender (4.2 LTS 以降、5.2 で確認) で、ゲームのキャラと同じ骨格に動きを付けて、
RusK の **Custom Motion** で再生できる glb を作る道具です。

## 流れ
1. **骨格を書き出す**: ゲームで RusK のメニュー **Model > ModelLab** を開き、「骨格を glb で書き出す (Blender 用)」を押す
   → `RusK\data\model\rig_キャラ名.glb` (今のキャラの骨格・体・テクスチャ)
   - **この glb はゲームのモデルそのものなので、配布しないでください** (自分で動きを作るためだけに使う)
2. **Blender で動きを付ける**: 骨格の glb を読み込んで、骨を回してキーを打つ。
   体の骨の名前 (`Bip001 Spine1`・`Bip001 R UpperArm` など) は全キャラ共通なので、どのキャラの骨格で作った動きも、ほかのキャラで使える
3. **glb で書き出す**: 骨とアニメーションだけを書き出す (メッシュ・テクスチャは入れない)。これは配っても大丈夫
4. **ゲームで使う**: `RusK\motions` に入れて、**Visual > CustomMotion > OpenWindow**
   - 動きを押すと、その場で再生 (試し用)
   - 「このキャラの動作」から動作 (Idle など) を選んでから動きを押すと、その動作に割り当て (その動作のときに自動で再生)

## スクリプトで作る
`rusk_motion.py` は、骨をワールドの向きで回してキーを打つ部品です。`wave.py` (手を振る) が見本です。

```
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --python wave.py -- rig_PinkLight_Show.glb RusK_Wave.glb preview.png
```

- 向き: X = キャラの左、-Y = キャラの前、Z = 上。`R(Y, 60)` は前から見て時計回り (右腕なら上がる)
- 骨は親から順に回す (`pose(t)` が返す並びの順)
- ねじれ用の骨 (`Bip001 RUpArmTwist` など) は、付いていく骨と一緒に自動で動かす (動かさないと袖が伸びる)

## 手で作るとき (Blender の画面で)
- 骨格の glb を **ファイル > インポート > glTF 2.0** で読み込み、アーマチュアを選んで **ポーズモード** で骨を回してキーを打つ
- 腕を回したら、同じ側の `UpArmTwist` / `ForeTwist` も同じだけ回す (上の理由)
- 書き出しは **ファイル > エクスポート > glTF 2.0** で、アーマチュアだけを選んで「選択したもののみ」、アニメーションをオン、スキンはオフ

## 仕組み (ゲーム側)
- 骨は名前 (根元からのパス) で対応させ、「glb の骨が基準の姿勢から回った分」をゲームの骨の基準の姿勢に掛ける。
  Blender が骨の向きを変えて読み込んでも、基準からの差なので同じ動きになる
- 上書きするのは、キーの値が動いている骨だけ。その子の骨はゲームの動きのまま付いていく (手を振るだけの動きなら、ほかはゲームの待機のまま)
- 再生の始めと終わりは 0.25 秒でゲームの動きと混ぜる。1 回きりの動作 (攻撃など) は、ゲームの動作の進み具合に合わせて再生する
